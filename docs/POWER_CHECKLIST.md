# Stage 0.7 供电与最小物料（设计，不要求现在接线）

目前没有独立舵机电源，所有运动阻塞。推荐 ESP32 USB 供电，舵机独立稳压供电；GPIO 仅用于经核实的信号，不能直接提供动力。3V3 不符合用户转述的 PM10D 4–6V 工作范围；开发板 5V 引脚未经电流能力验证禁止供舵机。原始 PM10D PDF 仍需核验。

| 最小物料 | 仍需确认规格 |
|---|---|
| 独立稳压直流电源 | 输出在已核验舵机允许范围；额定/瞬态电流依据启动、运行、堵转资料确定，目前 UNKNOWN，不指定安培数 |
| 电源开关/可达断电连接及保护 | 电压、电流、极性和保护额定值与最终电源/线缆匹配，人工能迅速切断舵机电源 |
| 电源线、连接器、分配端子 | 线径、电流容量、极性、防松脱和绝缘；不默认面包板能承受电机电流 |
| USB 数据线 | 已能枚举独立开发板；不能据此推断供舵机能力 |
| 信号/参考地连接线 | 核实三线引脚、公共 GND 设计和 GPIO 电平兼容；线色不等于引脚定义 |
| 固定支架及负载支撑 | 避免爪/物体掉落，人工断电后仍有支撑 |
| 万用表（现场核查用） | 由有能力人员核查电压/极性；不将表笔跨电源进行电流短接测量 |

后续检查：原 PDF → 电源容量/启动与堵转电流 → 正式引脚图/极性 → 共地、信号电平、无 USB 回灌 → 固定、保守机械范围 → 人工停止与负载支撑 → 具体接线/供电授权。当前全部未作为运动许可放行。不要通过人为堵转或扫动探测未知规格。

标称 10 kg·cm 不等于连续安全扭矩，也不等于真实夹持力。没有实际位置反馈，不用目标角度冒充测量。最终水杯增重自适应需额外负载/滑移证据，当前仅准备接触触发停止与授权释放。
