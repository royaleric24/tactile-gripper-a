# 公开副本与设备配置

此仓库从本地三个开发分支的隔离副本生成。保留提交顺序、父子关系和分支边界；脱敏改变了提交 SHA。原始工作区、原始历史和未提交实验成果均保留在本地，不属于此公开副本。

## 脱敏范围

- 历史文本中的个人主目录统一替换为 `/home/example`。这是展示用路径，不应作为运行目录。
- USB 序列号与串口节点使用 `EXAMPLE_ESP32`、`EXAMPLE_S3` 占位。
- 设备 MAC 使用 `02:00:00:00:00:01` 至 `02:00:00:00:00:03` 的示例标识。
- 本机作者邮箱改为账号的 GitHub noreply 地址。
- 含个人目录的四张历史截图（analysis / experiments，中英文版本）从公开历史排除。其余界面截图仅展示 UI 与模拟数据，不构成真实闭环验证证据。

历史记录中的 CONFIRMED / PASS 只保留原有验证范围；示例设备标识本身不再是原设备身份的证据。文档中指向旧提交的 SHA 是原本地历史引用，不保证能在公开仓库中解析。

## 使用真实设备前

公开配置不是即插即用的个人板卡配置。先枚举设备并核验板型、USB 信息和芯片身份，再在本地副本中填写实际串口、USB 序列号及 expected_mac。保留已有身份检查，不能通过删除检查来适配示例值。不要将真实唯一标识提交回公开分支。

原始 worktree 不应直接推送到此仓库，否则会重新引入未脱敏历史。迁移需要单独制定方案；当前未改写、替换或重新关联任何原工作区。

公开源码未附加开源许可证；可见性不等同于授予额外使用许可。第三方依赖依其自身许可证使用。
