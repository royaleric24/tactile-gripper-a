# Demo 交付计划 V2 | 2026-11-14

**性质**：兴趣/科展工程项目。目标是「真传感器—真控制—真杯子—加水」可演示；不是论文，不追求定量摩擦系数、复杂机器学习或严格统计显著性。

## 1. 最小可行成果

受控杯型、固定夹持位置和稳定机械安装下，操作员先在 MANUAL 将杯子夹住，切换 AUTO 后以真实 FSR 数据维持合理夹持，并在出现可检测的接触变化/滑移风险代理信号时向 ESP32-S3 发送真实 PWM 调整；Dashboard 同步显示两路 FSR、PWM、设备状态与日志。至少完成一次完整、可回放且视频可对齐的演示，再重复数次检验稳定性。**不要求必须先达到五次才允许展示初版。**

## 2. 成功标准分三级

| 级别 | 展示能力 | 诚实命名 |
|---|---|---|
| A（优先） | 真实 FSR 驱动实时 PWM，动态调节并完成加水过程，杯体未明显变形/滑落 | REAL_AUTO_DEMO |
| B（可靠备选） | 真实 FSR 检测 + MANUAL/辅助调节，操作员决定 PWM；完整真实日志和视频 | REAL_ASSISTED_DEMO |
| C（最低保底） | 真实传感器曲线/36点热图 + 稳定抓杯，AUTO 使用清楚标注的离线模拟或回放 | REAL_SENSING_PLUS_SIMULATION |

只报告实际达到的级别。给定脚本/定时 PWM 动作不能冒充「由反馈闭环触发」。

## 3. 开发顺序（整阶段交付，不拆成许多审核点）

### 第一阶段：硬件定型与最简信号路径
- 确认两片 FSR 的型号、尺寸、贴装位置、分压电路、ADC4 供电/CS/MISO、旧 ESP32 剩余引脚；先记录端口与板卡 ID。
- 单独采集两路 FSR，测空载、轻压、夹住杯、加水、卸载的原始数值/电压变化与滞后；确认至少能稳定判断「未接触/接触/较大压紧」。
- 6×6 行列扫描独立做逐行、逐列和相邻位置串扰测试；**矩阵失败不阻断 FSR-only 演示**。
- 交付：原始帧样例、短时连续日志、接线照片、`config` 真值表。

### 第二阶段：Mac 联调（优先）
- 统一传感器的 HELLO/SAMPLE 解析（允许 FSR-only 和 HYBRID 两套 profile）；采样数据和控制数据写同一个 Trial，但保持双设备身份、时间戳。
- 验证 Dashboard 的真实串口连接、两路 FSR 卡片、矩阵热图、数据有效/无效显示、CSV/回放。
- 在真实设备上复现 MANUAL 设定 `1300 μs` 的杯子夹持状态；检查 STOP、失联、重新连接和夹持保持表现。
- 交付：真实 LIVE 录屏、设备原始串口样例、命令/ACK 日志。

### 第三阶段：小规则闭环与科展演示
- 基线：在「刚接触且不明显变形」处获取两个 FSR 的参考区间。通过本杯实测设定“偏松”“合理”“偏紧”与最小等待时间。
- 只有新鲜有效的真实帧，且没有未完成 PWM 命令时，AUTO 才允许决策。若接触明显不足、且存在经过验证的滑移风险代理证据，才尝试适量收紧；若接触过强，则适量放松；其他情况保持。
- 每次执行保存 decision_reason、FSR1/2 原始数据、阈值/质量、PWM 目标、命令 ID/ACK、时间戳与视频标记。不要以 ACK 冒充舵机位置反馈。
- 交付：至少一条完整 REAL_AUTO_DEMO；有条件再做三次左右重复演示，记录失败而不是只留下成功视频。

## 4. 关键科学/工程边界（减少错误承诺）

- FSR 测的是受力相关电阻/电压变化，受机械接触面积、位置、非线性、滞后影响。初期只使用「相对接触强弱」，不输出牛顿或摩擦系数。
- **杯子变重 ≠ FSR 读数必然增加；杯子开始滑移 ≠ FSR 读数必然下降。** 水量变化是否触发可靠反馈，必须通过一轮真实加水记录验证。必要时增加低成本的外部滑移判据（例如贴标记点后用摄像头观察），但不作为当前硬件的前置要求。
- 两个 FSR 不能唯一恢复 36 个矩阵点的真实压力。可以用 FSR 做慢变基线/整体压力参考，矩阵只做去基线、接触位置和趋势展示；如果矩阵串扰严重，就不用于 AUTO。
- `1300 μs` 与 `1270 μs` 仅是此杯、此机械安装、此时的现场观察点。前者可作为人工起始参考，后者已出现形变，**不能直接定为自动控制可放心达到的目标**；可用范围另实测冻结。

## 5. 当前阻塞与建议分工

- 硬件组：机械接线、FSR 两路稳定信号、矩阵是否可用、固件、真实原始日志；优先提供**可解析的 FSR-only 帧**。
- 软件组：协议适配、UI 的 FSR 小卡片、记录、真实 MANUAL 联调、规则式 AUTO；**暂停非必要美化/统计页面功能**。
- 总负责人：确认杯子与夹持位置、两组接口字段、实机演示级别、集成分支 PR；只介入跨组协议或真实动作边界冲突。

## 6. 弹性实验安排

**最少**：双 FSR 三档响应、单次真实抓杯加水、传感器变化到 PWM 的真实链路、断连不继续收紧。**有余力**：3–5 次完整 Trial，比较固定 PWM / FSR 阈值 / 带滞回闭环，测矩阵鬼影和重复性。**时间充足**：视觉滑移辅助与多杯型。详细执行表见 [EXPERIMENTS_LITE_V2.md](EXPERIMENTS_LITE_V2.md)。

## 7. 不做的事情

暂不追求科研级压力标定、摩擦系数反演、训练机器学习模型、双侧 6×6、精密机械力反馈、复杂云端架构、学术报告格式和多版本 Dashboard 重做。
